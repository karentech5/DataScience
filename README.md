# DataScience

A comprehensive learning repository for data science fundamentals, feature engineering, and data analysis using Python.

## 📚 Repository Contents

### 1. **NumPy** (`numpy/`)

NumPy fundamentals and exercises for numerical computing:

- `intro-numpy.ipynb` - Introduction to NumPy arrays and basics
- `important-numpy-function.ipynb` - Essential NumPy functions
- `numpy-exercises.ipynb` - Practice exercises
- `numpy-exercises_with_solution.ipynb` - Solutions included
- `slicing.ipynb` - Array slicing techniques
- `flattening-arrays.ipynb` - Array reshaping and flattening

### 2. **Pandas** (`pandas/`)

Data manipulation and analysis with Pandas:

- `pandasdemo.ipynb` - Pandas introduction and demo
- `seriesanddataframe.ipynb` - Series and DataFrame fundamentals
- `selection.ipynb` - Data selection techniques
- `lociloc.ipynb` - Label and integer-location indexing
- `conndition.ipynb` - Conditional filtering
- `sorting.ipynb` - Sorting DataFrames
- `groupby.ipynb` - GroupBy operations
- `addingremoving.ipynb` - Adding/removing rows and columns
- `updating.ipynb` - Updating DataFrame values
- `Indexes - How to Set, Reset, and Use Indexes.ipynb` - Index management
- `datacleaning.ipynb` - Data cleaning techniques
- `data.csv` - Sample dataset

### 3. **Feature Engineering** (`FeatureEngineering/`)

Data preprocessing and feature engineering techniques:

- `DataCleaning.ipynb` - Handling missing values, outliers, and data quality
- `dataintegration.ipynb` - Merging and combining data
- `encoding.ipynb` - Categorical encoding techniques
- `Normalization.ipynb` - Data normalization (Min-Max scaling)
- `standarization.ipynb` - Data standardization (Z-score)
- `titanic_cleaned.csv` - Cleaned Titanic dataset
- `Titanic-Dataset.csv` - Original Titanic dataset

### 4. **Probability** (`Probability/`)

Probability and statistics concepts (coming soon)

## 🛠️ Prerequisites

- Python 3.8+
- Jupyter Notebook or JupyterLab
- Required libraries:
  ```bash
  pip install numpy pandas matplotlib seaborn scikit-learn
  ```

📦 Installation
Clone the repository:
git clone https://github.com/karentech5/DataScience.git
cd DataScience

Install dependencies:
pip install -r requirements.txt

Launch Jupyter:
jupyter notebook

2. Move to Pandas fundamentals in pandasdemo.ipynb
3. Learn Feature Engineering techniques in DataCleaning.ipynb
